FAQ

Questions, answered

Still stuck? Open an issue on GitHub.

How is this different from Chrome DevTools?

DevTools shows you everything: thousands of rules, overrides and framework classes. Layoutly gives you just the component you clicked, as small readable HTML + CSS and a prompt your AI understands — in one click.

Which websites does it work on?

Any website you can open in a browser. Layoutly has a built-in Chromium browser: type the address, press your key and click.

Does it work with ChatGPT, Claude, Cursor, v0, Lovable…?

Yes. The output is plain text. Choose your stack once and every prompt asks your AI for exactly that (React + Tailwind, Next.js, Vue, Svelte or HTML/CSS).

Is the download free?

Yes. Every day you get 2 components and 2 site styles for free — no card, no account. They come back each midnight. Need more in a day? $10 once makes it unlimited.

Is it really $10 forever?

Yes — one payment, no subscription, including future updates. Your license works on up to 3 of your computers. Prefer to build it yourself? The source code is free on GitHub.

What's the difference between open-source and $10?

Not the features — it's the same app. The code is MIT-licensed on GitHub: clone it, run “npm install” then “npm start”, and everything is unlocked, with no daily limit and no key. The $10 gets you the ready-made Mac and Windows installers (no Node.js, no terminal) and funds development.

Is it OK to copy other websites?

Layoutly is built for learning and inspiration: understanding how a layout is built and recreating the pattern in your own product. Don't copy brand assets, logos or copyrighted content.

My computer warns me before opening Layoutly.

That's expected: the installers aren't signed with a paid Apple or Microsoft certificate. The code is open on GitHub if you want to check what it does.

macOS: open Layoutly once and click “Done” on the warning. Then open System Settings → Privacy & Security, scroll down, click “Open Anyway” next to Layoutly and confirm. Windows: on the SmartScreen prompt, click “More info”, then “Run anyway”. You only do this once.
